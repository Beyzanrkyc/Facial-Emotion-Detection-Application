# Facial Emotion Detection

This project implements facial emotion detection using Convolutional Neural Networks (CNN), OpenCV, and the FER-2013 dataset.

## Overview

A deep learning application that detects and classifies human emotions from facial expressions in real-time using computer vision techniques and neural networks.

## Prerequisites

- Python 3.x
- OpenCV
- Streamlit
- CNN framework (TensorFlow/Keras or PyTorch)
- Other dependencies as specified in `requirements.txt`

## Dataset Setup

1. Download the FER-2013 dataset
2. Extract the `fer2013.zip` file
3. The extracted file will contain the dataset in CSV format

## Running the Application

To start the web application, run the following command:

```bash
streamlit run main.py
